# NoteMaker

Простой сайт на Python/Flask с регистрацией, входом и ролевой моделью.

## Возможности

- Регистрация: имя, почта, пароль и подтверждение пароля.
- Вход и выход из системы (пароли хранятся в хэшированном виде).
- Роли пользователей: **администратор**, **гость**, **студент**, **преподаватель**.
- Новый пользователь получает роль **«Гость»**. Первый зарегистрированный
  пользователь автоматически становится **администратором**.
- Администратор может просматривать список всех пользователей и изменять их роли.
- Все зарегистрированные пользователи могут загрузить статью в формате **PDF**
  и получить её краткое содержание (до 4000 символов), составленное языковой
  моделью через OpenAI-совместимый API (по умолчанию ProxyAPI) или GigaChat.
- Данные хранятся в базе данных **SQLite** (`users.db`).

## Запуск

```bash
# 1. Активировать виртуальное окружение (пакеты уже установлены)
source venv/bin/activate

# 2. Запустить приложение
python app.py
```

Откройте в браузере: http://127.0.0.1:5000

Первый зарегистрированный пользователь станет администратором — создайте
учётную запись и зайдите на страницу «Пользователи», чтобы назначать роли
другим участникам.

## Настройка языковой модели (.env)

Параметры обращения к языковой модели задаются в файле `.env`
(создайте его по образцу `.env.example`). Каждый тип LLM использует
свой набор переменных, поэтому для переключения между сервисами
достаточно изменить `LLM_API_TYPE` — ключи доступа хранятся независимо:

| Переменная        | Описание                                                                                               |
|-------------------|--------------------------------------------------------------------------------------------------------|
| `LLM_API_TYPE`    | Тип API: `openai` (OpenAI-совместимый) или `gigachat`                                                  |
| `OPENAI_API_KEY`  | API-ключ для OpenAI-совместимых сервисов                                                               |
| `OPENAI_API_URL`  | URL OpenAI-совместимого API (по умолчанию `https://api.proxyapi.ru/openai/v1` — ProxyAPI)              |
| `OPENAI_MODEL`    | Название модели (по умолчанию `gpt-4o-mini`)                                                           |
| `GIGACHAT_API_KEY`| Ключ разработчика GigaChat (строка в формате base64)                                                   |
| `GIGACHAT_API_URL`| URL GigaChat (по умолчанию `https://gigachat.devices.sberbank.ru/api/v1`)                              |
| `GIGACHAT_MODEL`  | Название модели GigaChat (по умолчанию `GigaChat-2`)                                                   |

Валидация окружения выполняется в модуле `config.py`: если `LLM_API_TYPE`
имеет недопустимое значение или не задан ключ доступа для выбранного типа
LLM, приложение завершится с понятным сообщением об ошибке.

Обращение к OpenAI-совместимому API выполняется через
`POST {LLM_API_URL}/chat/completions`, для GigaChat access_token получается
автоматически через OAuth 2.0 (`https://ngw.devices.sberbank.ru:9443/api/v2/oauth`).

## Установка окружения с нуля (если venv удалят)

```bash
python3 -m venv venv
venv/bin/pip install -r requirements.txt
```
